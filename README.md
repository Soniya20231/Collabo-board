
# 🧠 RealTime Whiteboard

**RealTime Whiteboard** is a collaborative, real-time whiteboard application that enables users to draw, brainstorm, and collaborate visually—together and in real-time. Perfect for remote teams, educators, designers, or anyone who needs to sketch ideas live with others.



## ✨ Features

- 🎨 Real-time drawing with smooth canvas sync
- 👥 Multi-user collaboration via WebSockets
- 📁 Create or join rooms for private sessions
- 🧼 Simple and intuitive UI
- 🔄 Auto-resizing and responsive design
- 🛠️ Built with modern web technologies

## 🛠️ Tech Stack

- **Frontend**: HTML5 Canvas, JavaScript (or TypeScript), React 
- **Backend**: Node.js, Express, Socket.IO
- **Real-time Sync**: WebSockets
